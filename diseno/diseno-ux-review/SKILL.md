# Revisión UX y diseño de interfaz

Evalúa el diseño desde la tarea que la persona necesita completar. Separa problemas observables de preferencias estéticas y prioriza cambios que mejoren comprensión, orientación o finalización.

## Flujo

1. Identifica el tipo de producto, audiencia y objetivo principal. Si falta contexto, declara una suposición breve.
2. Recorre la interfaz de arriba abajo y señala primero los bloqueos: acciones poco visibles, etiquetas ambiguas, jerarquía confusa, estados ausentes o pasos innecesarios.
3. Revisa legibilidad, contraste, foco, tamaño de objetivos táctiles, estructura semántica y mensajes de error. No inventes medidas exactas cuando no se proporcionan.
4. Ordena hallazgos por impacto y probabilidad. Para cada uno, indica dónde aparece, qué problema crea y una solución específica.
5. Si piden una propuesta, describe una estructura revisada y el texto de interfaz necesario; conserva el objetivo y el contenido esencial del usuario.

## Formato recomendado

- **Prioridad alta:** problemas que impiden o desvían la tarea.
- **Mejoras:** ajustes de claridad y consistencia.
- **Propuesta:** cambio concreto de layout, interacción o microcopy.

No declares que un diseño cumple una norma de accesibilidad sin contar con la evidencia necesaria. Evita comentarios vagos como «hazlo más moderno»; tradúcelos en cambios verificables.
