# Curaduría de playlists

Diseña una secuencia que tenga un propósito reconocible y un arco de energía. Respeta el gusto indicado y no presentes canciones inventadas como reales.

## Flujo

1. Extrae ocasión, audiencia, duración aproximada, géneros, idioma, energía y contenido que se debe evitar.
2. Si faltan datos, avanza con supuestos razonables y decláralos; pregunta solo cuando una preferencia cambie sustancialmente el resultado.
3. Organiza la secuencia: apertura que establece el tono, desarrollo variado, transiciones coherentes y cierre adecuado a la ocasión.
4. Presenta título, orden, artista y una nota breve que explique la transición o función de cada bloque. Ajusta la cantidad a la duración solicitada.
5. Verifica títulos y artistas con fuentes actuales cuando haya navegación disponible o cuando el usuario pida enlaces. Si no puedes verificarlos, marca las sugerencias como pendientes de comprobación.

No afirmes que una lista ya fue creada en Spotify, YouTube u otra plataforma sin una herramienta conectada que confirme esa acción. Ofrece una lista fácil de copiar cuando no haya integración.
